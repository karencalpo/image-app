# Image Gallery

This is an image gallery app that makes use of the following technologies. On the front-end, TypeScript/React was used along with Material UI for the styling of the components for this SPA.
On the back-end, Node.js was used for running the service and Express.js for the routing and APIs. I wrote APIs following RESTful standards. I used Multer, which is a middleware for Node.js and Express.js, that handles receiving and storing file uploads.

## Notes

The development of this took me around 10-12 hours. If I had more time, some of the improvements I would like to make on this app would be to add pagination. That would make things more robust for navigating through a large number of images. I would also prefer to use cloud storage to store files (such as Google Cloud) if I had more time on this app. I used Multer because I had to find a 
way to store files locally. Using cloud storage would have gone beyond the stated requirements for this app. I also would add more back-end validation of data if I had more time. I have some minor validation, but could add more to make the back-end more robust. Overall, it was an enjoyable app to build in a short amount of time.
